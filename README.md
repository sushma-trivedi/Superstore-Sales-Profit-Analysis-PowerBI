Superstore Sales & Profit Analysis Dashboard

Project Overview

This project analyzes Superstore sales, profit, quantity, and product performance using Power BI.

The dashboard provides interactive insights into business performance through different visualizations.

Key Features

- Total Sales and Total Profit KPI Analysis
- Monthly Sales Trend Analysis
- Sales Analysis by Category
- Regional Sales Performance
- Profit Analysis by Sub-Category
- State-wise Geographic Analysis
- Interactive Filters and Slicers

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Key Insights

- Identified top-performing product categories.
- Analyzed monthly sales trends.
- Compared sales and profit across different regions.
- Identified profitable and less profitable sub-categories.
